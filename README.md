# Warehouse Management AI Chatbot

A Generative AI chatbot that uses Retrieval-Augmented Generation (RAG) and data tools to help warehouse supervisors find orders at risk of missing their shipping deadline, understand why, and decide what to do, using warehouse orders, inventory, shipping, and labor attendance data.

## How it works
1. **Retrieve:** a TF-IDF retriever pulls the most relevant passages from the knowledge base (solution overview, operations playbook, data dictionary, analytics summary). IDs in the question (SO-, ORD, PRD, EMP) and dates (YYYY-MM-DD) are looked up directly.
2. **Query:** for exact numbers, Claude calls safe pandas tools: `query_table` (filter, group, aggregate, sort), `get_record`, and `daily_snapshot`. No model-written code is executed.
3. **Generate:** Claude answers using only the retrieved passages and query results. Each answer shows the passages and queries it used.

The system prompt (instructions plus table schemas) uses prompt caching, so repeat questions are faster and cheaper.

## Data (`data/`)
| File | Rows | Contents |
|---|---|---|
| warehouse_orders.csv | 2,000 | At-risk orders, Jul 1 to Nov 13 2026: delay probability, SHAP risk drivers, suggested action |
| inventory.csv | 100 | Products, stock, reorder level, location, price, status |
| shipping_delays.csv | 200 | Shipments, Sep to Nov 2026: expected vs actual ship date, delay days, reason, carrier |
| labor_attendance.csv | 7,080 | Daily attendance for 60 associates, Jul 1 to Nov 14 2026 |

Labor attendance is generated by `build/generate_labor_attendance.py` to line up with the other three files (same dates, lower Monday attendance, lower attendance on staffing-constraint delay dates, enough pickers each day to match `pickers_on_shift`). See `knowledge/data_dictionary.md` for every column.

## Files
- `streamlit_app.py`: app with Chat, Dashboard, Data explorer, and About tabs
- `rag.py`: retrieval, system prompt, and Claude tool-use loop
- `data_store.py`: loads the tables and implements the data tools
- `knowledge/`: documents the retriever searches
- `build/`: scripts that generate labor attendance and the analytics summary

## Configuration
In Streamlit Community Cloud, open **App settings > Secrets** and add:
```toml
ANTHROPIC_API_KEY = "your-key"
# optional
CLAUDE_MODEL = "claude-sonnet-5-5"
```

## Run locally
```
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Updating the data
Replace a CSV in `data/` with the same columns, then run `python build/build_knowledge.py` to refresh the analytics summary.

All data is synthetic and created for a graduate course project.
